# Healthcare Insurance Analysis

## Project Overview
The Healthcare Insurance Analysis project focuses on analyzing health insurance data to understand customer demographics, medical expenses, and the factors affecting insurance charges.

The project uses Python for data analysis and Power BI for interactive dashboard visualization.

## Objectives
- Analyze healthcare insurance data.
- Understand the relationship between Age, BMI, Smoking Status, and Insurance Charges.
- Identify patterns and trends in insurance costs.
- Create meaningful visualizations.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook
- Excel

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Dashboard Creation
6. Insights and Analysis

## Key Analysis
- Age vs Insurance Charges
- BMI vs Insurance Charges
- Smoker vs Non-Smoker Analysis
- Gender-wise Analysis
- Regional Analysis
- Medical Insurance Cost Analysis

## Dashboard
An interactive Power BI dashboard is created to present important insights and trends in healthcare insurance data.

## Conclusion
This project helps understand the major factors influencing healthcare insurance charges through data analysis and visualization.
